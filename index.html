Smart Library Simulation

A modern, interactive 3D educational library built from scratch using the Godot Engine.

About the Project

This project showcases a futuristic, non-blocky smart library designed for immersive digital learning. Moving away from traditional grid constraints, the simulation utilizes modern low-poly architecture, realistic global illumination, and interactive 2D user interfaces embedded within a 3D environment.

Key Features

  • First-Person Navigation: Smooth mouse-look and keyboard movement configuration built directly in Godot 4.
  • Interactive Smart Terminals: Trigger zones (Area3D) that allow users to open database records, read textbook pages, or solve pop-up quizzes.
  • Modern Architecture: Crafted using Constructive Solid Geometry (CSG) models for a sleek, realistic environment layout.
  • Realistic Ambiance: Utilizes advanced real-time global illumination for beautiful, light-filled study spaces.

How to Run the Game

1. Download and install the Godot Engine 4.x environment.

2. Clone or download this project source code from GitHub.

3. Open Godot, click "Import", and select the project.godot file inside this directory.

4. Press F5 to run the main simulation scene!
